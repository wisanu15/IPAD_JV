# IPAD_JV

Google Apps Script iPad management system with an Android PWA wrapper in `docs/`.

## Android install URL

Enable GitHub Pages from the `docs` folder, then open the GitHub Pages URL on Android Chrome and choose **Install app** or **Add to Home screen**.

The wrapper currently points to:

```text
https://script.google.com/macros/s/AKfycby079h5QsFuJtoOWk9E2-jJK1uhxnjlpw1Jrg-HthTxa5CeN15CRPyZCVxvHRYYdstmUQ/exec
```
